WCAG 1.4.3Level AA

Colour contrast (minimum)

Text must have a contrast ratio of at least 4.5:1 against its background (3:1 for large text) so low-vision users and people in bright sunlight can read it.

✓Good example: navy #0A3D7A text on white = 11.8:1 — passes comfortably.

WCAG 2.1.1Level A

Keyboard operable

All functionality must be usable with a keyboard alone. Use native controls (button, a, input) so focus and activation work by default.

✓Good example: a real <button> instead of a clickable <div>.

Mandatory footer elements

Every page must show contact information, “Last updated” date, copyright, terms, privacy policy and accessibility statement.

CWV · LCPPerformance

Largest Contentful Paint

The main content should render within 2.5s on mobile. Optimise hero images, avoid render-blocking scripts, and use caching.

✓Good example: compressed WebP hero + deferred non-critical JS.

UX · SearchHeuristic

Effective site search

Search should tolerate typos and synonyms, cover scheme names and everyday terms, and never return an empty dead-end.

✓Good example: “savings” returns NSC, KVP, RD with plain descriptions.
